# KTOC Learning Hub - Visual Preview Guide

## 🎬 How to View Your Project

### Running the Development Server
1. Open terminal in the project folder: `c:\dev\ktoc-hub-final`
2. Run: `npm run dev`
3. Open browser to: `http://localhost:5173`

## 🚀 Next Steps

### To Test the Project:
```bash
cd c:\dev\ktoc-hub-final
npm install          # If needed
npm run dev          # Start dev server
# Open http://localhost:5173 in browser
```

### To Build for Production:
```bash
npm run build        # Creates optimized build
npm run preview      # Preview production build locally
```

### To Customize:
Each page has configuration constants at the top - update these URLs:
- SharePoint links
- Confluence URL
- Chatbot URL
- Quick link URLs
- Community space URL
